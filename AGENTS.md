# AGENTS.md

# Проект

Это проект Telegram Mini App под названием "Куда ушло?".

Приложение помогает пользователю вести простой бытовой учёт расходов.

# Главное правило

Не использовать эмодзи нигде в продукте.

Эмодзи запрещены:

- в интерфейсе
- в кнопках
- в заголовках
- в категориях
- в пустых состояниях
- в отчётах
- в сообщениях Telegram-бота

# Стиль

Стиль приложения:
Soft fintech minimal.

Интерфейс должен быть:

- чистым
- современным
- спокойным
- взрослым
- mobile-first
- понятным

# Технологии frontend

Использовать:

- Vite
- React
- TypeScript
- обычный CSS
- localStorage для хранения данных

Не использовать:

- backend в первой версии
- database в первой версии
- UI-библиотеки
- chart-библиотеки
- emoji/icon packs
- Redux

# Экраны

Сделать 4 экрана:

1. Главная
2. Добавить расход
3. История
4. Настройки

# Данные

Expense:

- id
- amount
- category
- note
- date
- createdAt

Settings:

- dailyLimit
- currency

# Проверка

Перед завершением задачи нужно убедиться:

1. npm run build проходит.
2. TypeScript не выдаёт ошибок.
3. В интерфейсе нет эмодзи.
4. Логика соответствует PRODUCT_SPEC.md.
5. Приложение удобно на мобильном экране.
